📖 La misión: Un Bento Grid es ese diseño de cajas de distintos tamaños encajadas como una caja bento japonesa — lo verás en las webs más modernas. Vas a construir tu portafolio con ese estilo. Te damos las tarjetas en HTML; tú las acomodas en una cuadrícula solo con CSS Grid. Cada misión dice QUÉ lograr y QUÉ propiedades usar; el cómo lo resuelves tú. 🧩

📦 Tu punto de partida

Copia este HTML base (o abre base-grid.html) y trabaja dentro de <style>. Las tarjetas ya existen; tú las organizas con Grid.

FÁCIL Misión 1 · Levanta la cuadrícula

Concepto: display:grid + columnas + gap

Qué lograr

  • Convierte .bento en una cuadrícula de varias columnas iguales (empieza con 3 o 4).
  • Deja una separación uniforme entre todas las tarjetas.
  • Dale a cada .box fondo, padding y esquinas redondeadas para que se vean como tarjetas.
CSS .bento: display: grid grid-template-columns repeat() 1fr gap CSS .box: background padding border-radius
  • Las 6 tarjetas se acomodan en una rejilla con separación pareja.
+10 pts

FÁCIL Misión 2 · Dale altura a las celdas

Concepto: grid-auto-rows / grid-template-rows

Qué lograr

  • Haz que todas las filas tengan una altura mínima pareja, para que las tarjetas no queden aplastadas y el bento se vea equilibrado.
CSS .bento: grid-auto-rows (ej. un valor en px o minmax)
  • Todas las tarjetas tienen una altura base similar y consistente.
+15 pts

MEDIO Misión 3 · Una celda protagonista (2×2)

Concepto: grid-column span + grid-row span

Qué lograr

  • Haz que UNA tarjeta (ej. .intro o .foto) ocupe 2 columnas Y 2 filas, destacando como pieza central del bento.
CSS: grid-column: span 2 grid-row: span 2
  • Una tarjeta grande domina la composición; las demás se acomodan alrededor.
+10 pts

MEDIO Misión 4 · Una tarjeta de lado a lado

Concepto: grid-column con líneas (span / 1 / -1)

Qué lograr

  • Haz que otra tarjeta (ej. .frase) sea ancha: que ocupe 2 columnas o incluso toda la fila.
CSS: grid-column: span 2 ó grid-column: 1 / -1
  • La tarjeta elegida se extiende a lo ancho rompiendo la rejilla con gracia.
💡 Dato: la línea -1 siempre es la última; por eso 1 / -1 significa "de borde a borde".
+10 pts

MEDIO Misión 5 · Centra el contenido de cada caja

Concepto: alinear contenido dentro de la celda

Qué lograr

  • Que el texto de tarjetas como .foto y .frase quede centrado dentro de su caja (horizontal y vertical).
CSS (en la caja): display: grid place-items: center o bien: align-items justify-items text-align
  • El emoji y la frase quedan perfectamente centrados en su tarjeta.
+15 pts

DIFÍCIL Misión 6 · Maqueta con nombres (modo pro)

Concepto: grid-template-areas + grid-area

Qué lograr

  • En lugar de span, define la posición de cada tarjeta con nombres de áreas. Dibuja el bento como un mapa y asígnale a cada caja su nombre.
  • (Si ya lograste el layout con span en las misiones 3 y 4, este es el camino alternativo "elegante" — inténtalo aunque sea en una copia.)
CSS .bento: grid-template-areas CSS cada caja: grid-area: intro grid-area: foto …
  • El layout queda definido por un "mapa" de nombres, fácil de reordenar.
+10 pts

MEDIO Misión 7 · Responsive sin media queries

Concepto: repeat(auto-fit, minmax())

Qué lograr

  • Haz que la cuadrícula calcule sola cuántas columnas caben según el ancho de la pantalla, reacomodando las tarjetas al redimensionar.
CSS .bento: grid-template-columns repeat(auto-fit, minmax(…, 1fr))
  • Al achicar la ventana, las columnas se reducen solas sin escribir media queries.
+15 pts

PERSONALIZA Misión 8 · Hazlo TUYO

Aquí editas el contenido y la identidad visual

Qué lograr

  • Pon tu nombre y rol reales, tus skills verdaderas y un proyecto tuyo (con su enlace real con <a>).
  • Cambia la foto (emoji por una imagen real con <img>) y la frase por una que te represente.
  • Elige tu paleta de colores para las tarjetas (puedes dar colores distintos a la protagonista).
HTML: edita textos y agrega <a> con tus enlaces CSS: background color linear-gradient() box-shadow
  • El portafolio muestra info real tuya y al menos 1 enlace que funcione.

📤 Publica tu Bento Portafolio en GitHub Pages

  1. Crea un repositorio público en GitHub (ej. bento-portafolio) y sube tu archivo como index.html.
  2. Entra al repo → Settings → Pages. En "Branch" elige main y carpeta / (root). Guarda.
  3. Espera 1–2 min y copia la URL (algo como https://tu-usuario.github.io/bento-portafolio/).
  4. Comprueba que carga bien y se ve responsive.
  5. Entrega esa URL + una captura de tu bento.
💡 Puedes usar un solo repositorio con dos carpetas (/bio-card y /bento) para entregar las dos actividades juntas, o un repo para cada una. ¡Tú eliges!
