CSS

/* Layout general por áreas (Ej 5) */
.dash{
  display:grid;
  grid-template-columns: 150px 1fr 160px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "head head head"
    "side main aux"
    "foot foot foot";
  gap:10px;
  min-height:380px;
}
.head{ grid-area:head; } .side{ grid-area:side; } .main{ grid-area:main; }
.aux{ grid-area:aux; }   .foot{ grid-area:foot; }
.z{ border-radius:8px; padding:14px; color:#fff; }
.head{ background:#1e293b; font-weight:800; }
.side{ background:#7c3aed; } .side p{ margin:6px 0; }
.main{ background:#e2e8f0; color:#0f172a; }
.aux{ background:#334155; } .foot{ background:#0f172a; color:#94a3b8; text-align:center; }

/* Grid interno responsive de KPIs (Ej 2 + Ej 8) */
.cards{ display:grid; grid-template-columns: repeat(auto-fit, minmax(110px,1fr)); gap:10px; }
.kpi{ background:#fff; border:1px solid #cbd5e1; border-radius:8px; padding:14px; display:flex; flex-direction:column; gap:4px; }
.kpi b{ font-size:1.5rem; color:#7c3aed; } .kpi span{ font-size:.8rem; color:#475569; }
RETO EXTRA
🔥 Achica la ventana: el grid interno de KPIs (auto-fit) pasa solo de 4 a 2 y a 1 columna. Como reto mayor, añade una media query que en móvil cambie grid-template-areas para apilar todo en una sola columna.
