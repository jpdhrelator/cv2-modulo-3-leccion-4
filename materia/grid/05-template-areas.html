Grid · Ejercicio 5 de 10: grid-template-areas

Maquetar por nombres

DIFÍCIL CONCEPTO

grid-template-areas

La forma más legible de armar un layout completo: dibujas la estructura con nombres. Primero das un nombre a cada zona con grid-area, y luego "pintas" la cuadrícula con grid-template-areas usando esos nombres como si fuera un mapa.

Cada string es una fila; cada palabra, una celda. Repetir un nombre hace que esa zona se expanda. Un punto (.) deja una celda vacía. Es ideal para el layout clásico cabecera / barra lateral / contenido / pie.

RESULTADO EN VIVO

Así se ve 👇

header
sidebar
main
footer
SOLUCIÓN (HTML + CSS)

El código

HTML

      <div class="layout">
        <header class="zona head">header</header>
        <aside class="zona side">sidebar</aside>
        <main class="zona main">main</main>
        <footer class="zona foot">footer</footer>
      </div>

CSS

.layout{
  display:grid;
  grid-template-columns: 160px 1fr;
  grid-template-rows: auto 200px auto;
  grid-template-areas:
    "head head"
    "side main"
    "foot foot";
  gap:10px;
}
.head{ grid-area: head; }
.side{ grid-area: side; }
.main{ grid-area: main; }
.foot{ grid-area: foot; }
.zona{ color:#fff; border-radius:8px; display:flex; align-items:center; justify-content:center; font-weight:700; }
.head{ background:#1e293b; } .side{ background:#7c3aed; } .main{ background:#0ea5e9; } .foot{ background:#334155; }
RETO EXTRA
🔥 Mueve la barra lateral a la derecha cambiando la fila del medio a "main side" y las columnas a 1fr 160px. Sin tocar el HTML, el layout se reorganiza.
