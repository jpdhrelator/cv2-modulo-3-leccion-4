Grid · Ejercicio 7 de 10: Alinear la rejilla completa

justify-content y align-content

MEDIO CONCEPTO

Alinear la rejilla completa

Cuando la cuadrícula es más pequeña que su contenedor (por ejemplo, columnas en px que no llenan el ancho), puedes mover el bloque entero de la rejilla:

justify-content → posiciona la rejilla en horizontal dentro del contenedor.
align-content → la posiciona en vertical.
place-content → atajo de ambos.

No confundir con el ejercicio anterior: *-items mueve el contenido dentro de cada celda; *-content mueve la rejilla completa.

SOLUCIÓN (HTML + CSS)

El código

HTML

      <p class="pg-cap">justify-content: start (la rejilla a la izquierda)</p>
      <div class="g s"><span class="it">1</span><span class="it">2</span><span class="it">3</span></div>
      <p class="pg-cap">justify-content: center (rejilla centrada)</p>
      <div class="g c"><span class="it">1</span><span class="it">2</span><span class="it">3</span></div>
      <p class="pg-cap">justify-content: space-between</p>
      <div class="g b"><span class="it">1</span><span class="it">2</span><span class="it">3</span></div>

CSS

.g{ display:grid; grid-template-columns: 70px 70px 70px; gap:8px; background:#fff; border:1px solid #cbd5e1; border-radius:8px; padding:8px; margin-bottom:12px; }
.s{ justify-content:start; }
.c{ justify-content:center; }
.b{ justify-content:space-between; }
.it{ background:#16a34a; color:#fff; padding:16px; border-radius:6px; font-weight:700; text-align:center; }
RETO EXTRA
🔥 Cambia las columnas a 1fr 1fr 1fr: verás que justify-content deja de tener efecto, porque con fr la rejilla ya ocupa todo el ancho y no sobra espacio que repartir.
