FÁCIL CONCEPTO

display: grid

CSS Grid es un sistema de layout de dos dimensiones: maneja filas y columnas a la vez (a diferencia de flexbox, que es de una). Se activa con display:grid en un contenedor.

La propiedad estrella es grid-template-columns, donde defines cuántas columnas hay y qué ancho tiene cada una. Por ejemplo 150px 150px 150px crea 3 columnas de 150px. Los hijos se colocan solos en las celdas, de izquierda a derecha y de arriba a abajo.

SOLUCIÓN (HTML + CSS)

El código

HTML

      <div class="grid">
        <div class="item">1</div><div class="item">2</div><div class="item">3</div>
        <div class="item">4</div><div class="item">5</div><div class="item">6</div>
      </div>

CSS

.grid{
  display:grid;
  grid-template-columns: 150px 150px 150px;  /* 3 columnas de 150px */
  gap:12px;
}
.item{ background:#2563eb; color:#fff; padding:22px; border-radius:8px; text-align:center; font-weight:700; }
