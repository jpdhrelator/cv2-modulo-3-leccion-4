Responsive SIN media queries

DIFÍCIL CONCEPTO

minmax() y auto-fit

La joya de Grid para diseño adaptable. minmax(min, max) define un tamaño que nunca baja del mínimo ni supera el máximo: minmax(200px, 1fr) = "al menos 200px, pero crece si hay espacio".

Combinado con repeat(auto-fit, ...), el navegador calcula solo cuántas columnas caben y reacomoda los items al redimensionar — sin escribir una sola media query. La receta mágica: repeat(auto-fit, minmax(200px, 1fr)).

SOLUCIÓN (HTML + CSS)

El código

HTML

      <p class="pg-cap">repeat(auto-fit, minmax(160px, 1fr)) — reduce la ventana y míralo</p>
      <div class="grid">
        <div class="item">1</div><div class="item">2</div><div class="item">3</div>
        <div class="item">4</div><div class="item">5</div><div class="item">6</div>
      </div>

CSS

.grid{
  display:grid;
  grid-template-columns: repeat(auto-fit, minmax(160px, 1fr));
  gap:12px;
}
.item{ background:#db2777; color:#fff; padding:28px; border-radius:8px; text-align:center; font-weight:700; }
RETO EXTRA
🔥 Cambia auto-fit por auto-fill y reduce la ventana hasta que sobren columnas: auto-fit estira los items para llenar el ancho; auto-fill deja columnas vacías reservadas.
