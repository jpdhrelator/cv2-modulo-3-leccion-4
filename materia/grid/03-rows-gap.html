grid-template-rows y separación

FÁCIL CONCEPTO

Filas y gap

Igual que las columnas, puedes definir las filas con grid-template-rows. Por ejemplo 100px 100px crea dos filas de 100px de alto.

gap controla el espacio entre celdas. Puedes separarlo en row-gap (entre filas) y column-gap (entre columnas). Las filas que no definas explícitamente toman el tamaño de su contenido (o el valor de grid-auto-rows).

SOLUCIÓN (HTML + CSS)

El código

HTML

      <div class="grid">
        <div class="item">1</div><div class="item">2</div><div class="item">3</div>
        <div class="item">4</div><div class="item">5</div><div class="item">6</div>
      </div>

CSS

.grid{
  display:grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 80px 120px;   /* fila 1 de 80px, fila 2 de 120px */
  row-gap: 20px;
  column-gap: 10px;
}
.item{ background:#16a34a; color:#fff; border-radius:8px; display:flex; align-items:center; justify-content:center; font-weight:700; }
RETO EXTRA
🔥 Pon row-gap: 0 y sube column-gap a 30px. Observa que ahora las filas quedan pegadas pero las columnas muy separadas: son dos espacios independientes.
