Grid · Ejercicio 2 de 10: La unidad fr y repeat()

Columnas flexibles

FÁCIL CONCEPTO

La unidad fr y repeat()

Definir anchos fijos en píxeles no es flexible. La unidad fr ("fracción") reparte el espacio disponible: 1fr 1fr 1fr son 3 columnas que se reparten el ancho por igual y se adaptan al contenedor.

repeat() evita repetir: repeat(3, 1fr) equivale a 1fr 1fr 1fr. Y puedes mezclar proporciones: 2fr 1fr 1fr hace la primera columna del doble de ancho que las otras dos.

RESULTADO EN VIVO

Así se ve 👇

grid-template-columns: repeat(3, 1fr)

1
2
3

grid-template-columns: 2fr 1fr 1fr

2fr
1fr
1fr
SOLUCIÓN (HTML + CSS)

El código

HTML

      <p class="pg-cap">grid-template-columns: repeat(3, 1fr)</p>
      <div class="g iguales"><div class="item">1</div><div class="item">2</div><div class="item">3</div></div>
      <p class="pg-cap">grid-template-columns: 2fr 1fr 1fr</p>
      <div class="g desigual"><div class="item">2fr</div><div class="item">1fr</div><div class="item">1fr</div></div>

CSS

.g{ display:grid; gap:12px; margin-bottom:12px; }
.iguales{ grid-template-columns: repeat(3, 1fr); }
.desigual{ grid-template-columns: 2fr 1fr 1fr; }
.item{ background:#0ea5e9; color:#fff; padding:22px; border-radius:8px; text-align:center; font-weight:700; }
RETO EXTRA
🔥 Cambia a repeat(4, 1fr) y agrega un item más en el HTML. Las columnas siempre se reparten el ancho por igual, sin importar el tamaño de la pantalla.
