Flexbox · Ejercicio 5 de 10: flex-wrap y gap

Cuando los items no caben

MEDIO CONCEPTO

flex-wrap y gap

Por defecto, los flex items se encogen para caber todos en una sola línea (flex-wrap: nowrap). Con flex-wrap: wrap permites que, cuando no quepan, salten a la siguiente línea manteniendo su tamaño.

gap define el espacio entre items (y entre filas cuando hay wrap), sin necesidad de márgenes. La combinación flex-wrap: wrap + gap es la base de las galerías y rejillas de tarjetas flexibles.

RESULTADO EN VIVO

Así se ve 👇

flex-wrap: nowrap — se encogen para caber

Item 1Item 2Item 3Item 4Item 5

flex-wrap: wrap — saltan de línea

Item 1Item 2Item 3Item 4Item 5
SOLUCIÓN (HTML + CSS)

El código

HTML

      <p class="pg-cap">flex-wrap: nowrap — se encogen para caber</p>
      <div class="d nowrap"><span class="it">Item 1</span><span class="it">Item 2</span><span class="it">Item 3</span><span class="it">Item 4</span><span class="it">Item 5</span></div>
      <p class="pg-cap">flex-wrap: wrap — saltan de línea</p>
      <div class="d wrap"><span class="it">Item 1</span><span class="it">Item 2</span><span class="it">Item 3</span><span class="it">Item 4</span><span class="it">Item 5</span></div>

CSS

.d{ display:flex; gap:10px; background:#fff; border:1px solid #cbd5e1; border-radius:6px; padding:10px; margin-bottom:12px; }
.nowrap{ flex-wrap:nowrap; }
.wrap  { flex-wrap:wrap; }
.it{ background:#db2777; color:#fff; padding:14px 22px; border-radius:6px; font-weight:700; white-space:nowrap; }
