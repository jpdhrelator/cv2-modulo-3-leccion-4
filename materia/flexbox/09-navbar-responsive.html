Flexbox · Ejercicio 9 de 10: Navbar con flexbox

Un componente real

DIFÍCIL CONCEPTO

Navbar con flexbox

Ahora aplicamos flexbox a un caso real: una barra de navegación. El patrón es: display:flex + justify-content:space-between (logo a un extremo, menú al otro) + align-items:center (todo a la misma altura).

El truco margin-left:auto en un item "empuja" todo lo que sigue hacia la derecha, absorbiendo el espacio libre — muy útil para separar un botón de acción. Con flex-wrap:wrap la barra se adapta cuando no hay espacio.

RESULTADO EN VIVO

Así se ve 👇

🍕 MiSitio Inicio Menú Nosotros Ordenar
SOLUCIÓN (HTML + CSS)

El código

HTML

      <nav class="navbar">
        <span class="logo">🍕 MiSitio</span>
        <a href="#">Inicio</a>
        <a href="#">Menú</a>
        <a href="#">Nosotros</a>
        <a href="#" class="cta">Ordenar</a>
      </nav>

CSS

.navbar{
  display:flex;
  align-items:center;       /* todo centrado verticalmente */
  gap:18px;
  flex-wrap:wrap;
  background:#1e293b;
  padding:14px 22px;
  border-radius:8px;
}
.navbar .logo{ font-weight:800; color:#fff; margin-right:auto; } /* empuja el resto a la derecha */
.navbar a{ color:#cbd5e1; text-decoration:none; font-weight:600; }
.navbar a:hover{ color:#fff; }
.navbar .cta{ background:#22c55e; color:#052e16; padding:8px 16px; border-radius:6px; }
RETO EXTRA
🔥 Cambia margin-right:auto del logo por quitarlo y poner margin-left:auto en el enlace .cta. Observa cómo ahora es el botón «Ordenar» el que se separa solo hacia la derecha.
