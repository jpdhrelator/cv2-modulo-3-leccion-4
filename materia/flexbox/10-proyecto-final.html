PROYECTO CONCEPTO

Proyecto: página completa con flexbox

¡Hora de integrar todo! Esta es una landing real (cafetería) construida solo con flexbox. Reconoce cada concepto: la navbar usa flex + space-between (Ej 9), el hero usa direction:column + centrado perfecto (Ej 8), las tarjetas usan wrap + flex:1 (Ej 5 y 6), y el footer usa space-between + align-items (Ej 3 y 4).

Lee el código completo abajo: es la meta a la que llegarás tras dominar los ejercicios.

CSS

/* Contenedor general en columna */
.page{ display:flex; flex-direction:column; gap:14px; }

/* NAVBAR (Ej 9): flex + space-between + align-items */
.nav{ display:flex; justify-content:space-between; align-items:center; background:#1e293b; padding:14px 20px; border-radius:8px; }
.nav .brand{ color:#fff; font-weight:800; }
.nav .links{ display:flex; gap:16px; }
.nav .links a{ color:#cbd5e1; text-decoration:none; font-weight:600; }

/* HERO (Ej 2 + Ej 8): direction column + centrado perfecto */
.hero{ display:flex; flex-direction:column; justify-content:center; align-items:center; gap:8px; text-align:center;
       min-height:180px; background:linear-gradient(135deg,#7c3aed,#db2777); color:#fff; border-radius:10px; padding:24px; }
.hero h2{ margin:0; }
.hero .btn{ background:#fff; color:#7c3aed; padding:10px 22px; border-radius:8px; font-weight:700; text-decoration:none; }

/* CARDS (Ej 5 + Ej 6): wrap + flex:1 para que se repartan igual */
.cards{ display:flex; flex-wrap:wrap; gap:14px; }
.card{ flex:1; min-width:160px; display:flex; flex-direction:column; gap:6px;
       background:#fff; border:1px solid #e2e8f0; border-radius:10px; padding:18px; }
.card h3{ margin:0; }
.card .price{ margin-top:auto; font-weight:800; color:#7c3aed; } /* margin-top:auto empuja el precio abajo */

/* FOOTER (Ej 3 + Ej 4): space-between + center */
.foot{ display:flex; justify-content:space-between; align-items:center; background:#0f172a; color:#94a3b8; padding:16px 20px; border-radius:8px; }
RETO EXTRA
🔥 Haz la sección de tarjetas más "responsive": dale a .card un min-width mayor (ej. 240px) y reduce la ventana. Gracias a flex-wrap, las tarjetas pasarán solas de 3 en fila a 2 y luego a 1.
