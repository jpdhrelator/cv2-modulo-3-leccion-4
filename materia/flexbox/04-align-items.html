Flexbox · Ejercicio 4 de 10: align-items

Alinear en el EJE CRUZADO

MEDIO CONCEPTO

align-items

align-items alinea los items en el eje cruzado (vertical si la dirección es row). Para notarlo, el contenedor debe tener altura:

stretch: los items se estiran para llenar el alto (por defecto).
flex-start: alineados arriba.
center: centrados verticalmente.
flex-end: alineados abajo.
baseline: alineados por la línea base del texto.

Mientras justify-content trabaja el eje principal, align-items trabaja el cruzado. Juntos colocan los items donde quieras.

SOLUCIÓN (HTML + CSS)

El código

HTML

      <p class="pg-cap">align-items: stretch (por defecto)</p>
      <div class="d ai-stretch"><span class="it">A</span><span class="it">B</span><span class="it">C</span></div>
      <p class="pg-cap">align-items: flex-start</p>
      <div class="d ai-start"><span class="it">A</span><span class="it">B</span><span class="it">C</span></div>
      <p class="pg-cap">align-items: center</p>
      <div class="d ai-center"><span class="it">A</span><span class="it">B</span><span class="it">C</span></div>
      <p class="pg-cap">align-items: flex-end</p>
      <div class="d ai-end"><span class="it">A</span><span class="it">B</span><span class="it">C</span></div>

CSS

.d{ display:flex; gap:8px; height:90px; background:#fff; border:1px solid #cbd5e1; border-radius:6px; padding:8px; margin-bottom:10px; }
.ai-stretch{ align-items:stretch; }
.ai-start  { align-items:flex-start; }
.ai-center { align-items:center; }
.ai-end    { align-items:flex-end; }
.it{ background:#16a34a; color:#fff; padding:10px 16px; border-radius:6px; font-weight:700; }
RETO EXTRA
🔥 Quita la propiedad height del contenedor: verás que align-items deja de notarse, porque sin altura el eje cruzado no tiene espacio que repartir.
