Flexbox · Ejercicio 3 de 10: justify-content

Repartir en el EJE PRINCIPAL

MEDIO CONCEPTO

justify-content

justify-content distribuye los items a lo largo del eje principal (horizontal si la dirección es row). Es la propiedad que usas para alinear y repartir el espacio sobrante:

flex-start: todos al inicio (por defecto).
center: agrupados al centro.
flex-end: todos al final.
space-between: primero y último pegados a los bordes, el resto del espacio repartido entre ellos.
space-around: espacio igual alrededor de cada item (los bordes quedan con media porción).
space-evenly: espacio idéntico entre items y también en los bordes.

SOLUCIÓN (HTML + CSS)

El código

HTML

      <p class="pg-cap">justify-content: flex-start</p>
      <div class="d jc-start"><span class="it">A</span><span class="it">B</span><span class="it">C</span></div>
      <p class="pg-cap">justify-content: center</p>
      <div class="d jc-center"><span class="it">A</span><span class="it">B</span><span class="it">C</span></div>
      <p class="pg-cap">justify-content: flex-end</p>
      <div class="d jc-end"><span class="it">A</span><span class="it">B</span><span class="it">C</span></div>
      <p class="pg-cap">justify-content: space-between</p>
      <div class="d jc-between"><span class="it">A</span><span class="it">B</span><span class="it">C</span></div>
      <p class="pg-cap">justify-content: space-around</p>
      <div class="d jc-around"><span class="it">A</span><span class="it">B</span><span class="it">C</span></div>
      <p class="pg-cap">justify-content: space-evenly</p>
      <div class="d jc-evenly"><span class="it">A</span><span class="it">B</span><span class="it">C</span></div>

CSS

.d{ display:flex; background:#fff; border:1px solid #cbd5e1; border-radius:6px; padding:8px; margin-bottom:10px; }
.jc-start  { justify-content:flex-start; }
.jc-center { justify-content:center; }
.jc-end    { justify-content:flex-end; }
.jc-between{ justify-content:space-between; }
.jc-around { justify-content:space-around; }
.jc-evenly { justify-content:space-evenly; }
.it{ background:#7c3aed; color:#fff; padding:10px 16px; border-radius:6px; font-weight:700; margin:0 1px; }
RETO EXTRA
🔥 Mira de cerca la diferencia entre space-around y space-evenly: en around los huecos de los extremos son la mitad que los del centro; en evenly todos los huecos son iguales.
