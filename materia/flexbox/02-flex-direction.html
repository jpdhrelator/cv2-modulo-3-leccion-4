Flexbox · Ejercicio 2 de 10: flex-direction

Elegir la dirección del eje principal

FÁCIL CONCEPTO

flex-direction

flex-direction define hacia dónde apunta el eje principal, es decir, en qué dirección se colocan los items:

row (por defecto): en fila, de izquierda a derecha.
row-reverse: en fila, pero de derecha a izquierda.
column: en columna, de arriba a abajo.
column-reverse: en columna, de abajo a arriba.

Cambiar la dirección también intercambia los ejes: con column, el eje principal pasa a ser vertical y el cruzado horizontal. Esto es clave para entender las próximas propiedades.

RESULTADO EN VIVO

Así se ve 👇

SOLUCIÓN (HTML + CSS)

El código

HTML

      <p class="pg-cap">flex-direction: row (por defecto)</p>
      <div class="d row"><span class="it">1</span><span class="it">2</span><span class="it">3</span></div>
      <p class="pg-cap">flex-direction: row-reverse</p>
      <div class="d rowr"><span class="it">1</span><span class="it">2</span><span class="it">3</span></div>
      <p class="pg-cap">flex-direction: column</p>
      <div class="d col"><span class="it">1</span><span class="it">2</span><span class="it">3</span></div>

CSS

.d{ display:flex; gap:8px; background:#fff; border:1px solid #cbd5e1; border-radius:6px; padding:8px; margin-bottom:10px; }
.row { flex-direction:row; }
.rowr{ flex-direction:row-reverse; }
.col { flex-direction:column; }
.it{ background:#0ea5e9; color:#fff; padding:10px 14px; border-radius:6px; font-weight:700; }
