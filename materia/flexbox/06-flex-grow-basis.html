Flexbox · Ejercicio 6 de 10: flex: grow, shrink y basis

Repartir el espacio disponible

MEDIO CONCEPTO

flex: grow, shrink y basis

Las propiedades van en los items (no en el contenedor) y deciden cómo se reparte el espacio:

flex-grow: cuánto crece un item para ocupar el espacio sobrante (0 = no crece).
flex-shrink: cuánto se encoge si falta espacio.
flex-basis: el tamaño base antes de crecer o encoger.

El atajo flex: 1 equivale a flex-grow:1; flex-shrink:1; flex-basis:0 → "toma una parte igual del espacio". Un patrón clásico: una barra lateral de ancho fijo y un contenido principal con flex:1 que ocupa el resto.

El código

HTML

      <p class="pg-cap">Los tres con flex: 1 → se reparten igual</p>
      <div class="d"><span class="it f1">flex:1</span><span class="it f1">flex:1</span><span class="it f1">flex:1</span></div>
      <p class="pg-cap">El del centro con flex: 2 → toma el doble</p>
      <div class="d"><span class="it f1">flex:1</span><span class="it f2">flex:2</span><span class="it f1">flex:1</span></div>
      <p class="pg-cap">Sidebar fija + main flexible</p>
      <div class="d"><span class="it side">sidebar 200px</span><span class="it f1">main (flex:1)</span></div>

CSS

.d{ display:flex; gap:10px; background:#fff; border:1px solid #cbd5e1; border-radius:6px; padding:10px; margin-bottom:12px; }
.it{ background:#0ea5e9; color:#fff; padding:16px; border-radius:6px; font-weight:700; text-align:center; }
.f1{ flex:1; }
.f2{ flex:2; }
.side{ flex:0 0 200px; background:#334155; }
